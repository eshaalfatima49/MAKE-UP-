## 🎯 HOW TO GET STARTED

### **Step 1: Read Documentation (5 minutes)**
Start with [README.md](README.md) for overview, then [SETUP.md](SETUP.md) for detailed instructions.

### **Step 2: Setup Supabase (10 minutes)**
1. Create account at supabase.com
2. Create new project
3. Run SUPABASE_SETUP.sql in SQL Editor
4. Get your Supabase URL and Anon Key

### **Step 3: Setup Local Environment (10 minutes)**
```bash
cd "make up store"
npm install
# Add credentials to .env file
npm run dev
```

### **Step 4: Test Locally (15 minutes)**
- Browse products
- Sign up and login
- Add products (as seller)
- Add to cart
- Place order

### **Step 5: Deploy to Production (15 minutes)**
Follow [DEPLOYMENT.md](DEPLOYMENT.md) to deploy to Vercel or Netlify

**Total Time: ~1 hour from start to live website**
